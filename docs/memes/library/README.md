# Meme library

Gravel God memes that were drawn and fact-checked for the two essays but don't run in them. Matt
reviewed the gallery of all 35 on 2026-10-09; 18 run in the essays (12 in Sweet Spot, 6 in the
training-app essay) and these 17 are kept for social posts and later articles.

Each meme is here twice:

- `<slug>.png`: the 1x desktop render. Upload this one to Instagram, X or Substack.
- `<slug>@2x.webp`: the 2x desktop render, for a web page.

Phone layouts (`-m.webp`) aren't kept here. If a meme moves into an essay, re-render it in
dirt-craft-course (see `../README.md`) to get them. Every caption uses only the essay's own claims and
numbers; the quote column is the essay text that supports it (all passed the fact-check).
