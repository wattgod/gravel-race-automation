# Newsletter confirmations

The dedicated **Gravel God Newsletter Reporting** Apps Script runs `runNewsletterAttribution` every five minutes in gravelgodcoaching@gmail.com. Its manifest requests Gmail read-only access, external requests, trigger management, and the executing account identity. It cannot send, modify, or delete mail. Gmail's scope technically permits reading the mailbox; this code searches only Substack subscriber notifications.

Deploy `Code.gs` and `appsscript.json` through Apps Script's editor, enable the manifest's Gmail advanced service, set the private `NEWSLETTER_INGEST_SECRET` script property, and run `installNewsletterAttribution`. The secret must match the Worker and WordPress option `gg_newsletter_ingest_secret`. Never commit secrets. The relay transfers the signup address plus message authentication evidence; the Worker stores an HMAC identity, not the address.

The private report is **WordPress → Tools → Newsletter report**, `/wp-admin/tools.php?page=gg-newsletter-report`. The starting export is separate from new authenticated confirmations. Existing subscribers cannot generate new article credit. Historical website sources without an article path stay unknown. New attempts match the latest website handoff within 30 days before confirmation. Article credit is fixed once assigned. Substack's **Require email address confirmation** must stay enabled; individual free/paid publisher signup notifications must stay enabled and unbatched. The report counts gross confirmed acquisitions, not current active subscribers or revenue.

All four native welcomes use `/newsletter/read/?gg_welcome=sweet-spot|unbound|kids`. WordPress records an allowlisted click and redirects even when reporting fails. Anonymous clicks are aggregate. Existing analytics consent enables a random browser cookie; distinct browsers are not distinct people or an email click-through rate. Known bots/prefetch are filtered; unidentified scanners may remain.

The report's **Include test activity** option includes owned `gravelgodcoaching+newsletter-*` aliases and test clicks. Administrators' clicks are tests. For a signed-out test browser, a one-hour HMAC marker can set the HttpOnly test cookie through `/newsletter/read/?gg_newsletter_test=<expiry>.<HMAC-SHA256("newsletter-test:"+expiry, INGEST_SECRET)>`. This marker grants no account access. Do not publish it or use it in reader emails.

Run `node --test workers/newsletter-attribution/worker.test.mjs`. Deploy the Worker using its Wrangler config and the WordPress plugin using `scripts/push_wordpress.py --sync-newsletter-report --purge-cache`. Keep `ALLOW_LOCAL_TEST=false` in production. If last sync is older than 30 minutes or a notification is rejected, the report warns that counts may be incomplete. Check Apps Script Executions and repair the relay before trusting new conversion totals. Repeated syncs are idempotent.
